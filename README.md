# kalemin-ucunun-sinavda-kirilmasi-olcme-secme-ve-yerlestirme-merkezi
Kalem ucunun sınavda kırılmasını resmi ölçme sapması, milli cevap güvenliği krizi ve yerleştirme hakkı ihlali sayan; ucu optik form, kapağı kılavuz, 'yedek kalemim vardı' cümlesini ek süre talebi ilan eden Merkez. Gerçekten çalışır. Uçlar artık sorudur.
